### 🎨 About Me
아이디어를 단순히 시각화하는 것에서 그치지 않고, 사용자 경험을 고민하며 **기획 → UX/UI 디자인 → 웹 구현 → 배포**까지 직접 만들어가는 과정 배웠습니다.

Figma를 활용한 화면 설계와 프로토타이핑부터 HTML/CSS/JavaScript 기반의 웹 구현, React/Vite를 활용한 인터랙티브한 웹 제작까지 경험하고 있습니다.

특히 **AI 도구를 작업 과정에 적극적으로 활용**해 아이디어를 빠르게 구체화하고, 반복적인 작업은 효율적으로 줄이면서 결과물의 완성도를 높이는 방식으로 작업하고 있습니다.
